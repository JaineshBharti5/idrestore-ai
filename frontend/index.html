    How it works

    Two images. One handle. Zero fuss.

    Upload a degraded file and the pipeline does the rest. You always keep the original next to the result.

    01 · Upload

    Add one file or a batch. The tool fixes orientation, then measures blur, noise, contrast and faces to decide what each file needs.

    02 · Restore

    Denoise, upscale, restore faces, then tune levels and sharpness. Documents also get shadows and paper tint removed.

    03 · Verify

    Drag the handle to compare. Scores show how much sharper the file is and whether photos, text and layout still match.

    The pipeline

    Send a file. Get a verdict.

    The same stages run in the studio, the API and the batch command, so results match everywhere.

    • Faces stay the same person. Model output is blended with the original face.
    • Documents keep their layout. Edge maps and OCR text are compared before and after.
    • Every file gets a report. Download HTML for one file, ZIP and CSV for a batch.
